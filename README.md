# Shipping Operations & Freight Cost Analytics

## Project Overview
This project analyzes shipping operations, delivery performance, and freight costs using Excel, SQL, and Power BI. It demonstrates how data analytics can support logistics and supply chain decision-making.

**Note:** This is a portfolio project built using simulated practice data. It does not use actual company data.

## Business Objectives
- Analyze shipment volumes and delivery status.
- Measure delivery and shipment delay rates.
- Compare estimated and actual freight costs.
- Evaluate freight costs and delay rates across shipping modes.
- Present key operational metrics through an interactive Power BI dashboard.

## Tools & Technologies
- **Microsoft Excel:** Data inspection, cleaning, and validation.
- **MySQL:** Data storage, SQL queries, aggregations, and joins.
- **Power BI:** Data modeling, DAX measures, KPI cards, and visualizations.

## Dataset
The practice dataset contains 300 shipment records, along with customer and route reference tables.

Key fields include:
- Shipment ID and booking date
- Customer and route information
- Shipping mode and shipment status
- Cargo weight and planned transit days
- Estimated and actual freight costs
- Planned and actual delivery dates
- Shipment delay days

## Key Performance Indicators
- **Total Shipments:** 300
- **Delivery Rate:** 99%
- **Delayed Shipments:** 124
- **Total Actual Freight Cost:** $332,598.86

These results describe the simulated dataset and are not real-world company performance figures.

## Dashboard Analysis
The Power BI dashboard includes:
1. Shipment volume and delivery performance KPIs
2. Shipment status distribution
3. Delay rate by shipping mode
4. Estimated versus actual freight cost by shipping mode

## Skills Demonstrated
Data cleaning, data validation, SQL queries, table joins, data modeling, DAX measures, KPI development, dashboard design, and logistics analytics.

## Conclusion
This project demonstrates an end-to-end analytics workflow, from preparing logistics data and querying it with SQL to building a Power BI dashboard that highlights shipping performance and freight cost patterns.
